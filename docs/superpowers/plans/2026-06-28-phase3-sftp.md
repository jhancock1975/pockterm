# Phase 3: SFTP — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development or superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Browse, transfer, and manage files on a host over SFTP: a remote file browser with navigation, upload/download with a transfer queue, and rename/delete/mkdir/chmod.

**Architecture:** An `SFTPService` actor opens its own SSH connection (reusing `SSHCredentials` + the host-key validator) and the SFTP subsystem via Citadel. Pure helpers (POSIX mode → kind/permissions, path joining) are TDD'd. A `FilesBrowserView` lists a remote directory and drives operations; a `TransferQueue` (@Observable) tracks uploads/downloads. Networking is device-verified.

**Tech Stack:** Citadel SFTP (`SFTPClient`, `SFTPFile`, `SFTPFileAttributes`), SwiftUI, SwiftData (none new). No new packages.

## Global Constraints

- Same as prior phases: iOS 26.5+, Swift 5 mode, secrets only via `SecretStore`.
- Reuse `SSHCredentials`, `PresentedHostKey`, and the known-hosts decision flow from Phase 1/2.5 for the SFTP connection's host-key validation.
- New app files auto-compile (synchronized folder); new TEST files need `ruby scripts/setup_project.rb`.

### Task 2: SFTPService (connect + operations)

**Files:**
- Create: `pockterm/SFTP/SFTPService.swift`

**Interfaces:**
- Produces an `actor SFTPService` with:
  - `func connect(_ creds: SSHCredentials, onHostKey: @escaping @Sendable (PresentedHostKey) async -> Bool) async throws`
  - `func list(_ path: String) async throws -> [RemoteFile]`
  - `func realPath(_ path: String) async throws -> String`
  - `func download(_ path: String) async throws -> Data`
  - `func upload(_ data: Data, to path: String) async throws`
  - `func makeDirectory(_ path: String) async throws`
  - `func remove(_ path: String) async throws` / `func removeDirectory(_ path: String) async throws`
  - `func rename(_ from: String, to: String) async throws`
  - `func chmod(_ path: String, mode: UInt32) async throws`

- Consumes: Citadel `SSHClient.connect(... hostKeyValidator: .custom(CallbackHostKeyValidator) ...)`, `client.openSFTP()`, `SFTPClient.listDirectory/openFile/createDirectory/remove/rmdir/rename/setAttributes`, `SFTPFile.readAll/write/close`, `SFTPFileAttributes(permissions:)`.

**Note:** Maps `SFTPMessage.Name` path components to `RemoteFile` via `RemoteFile.kind(fromMode:)`. Filters `.` and `..`. Device-verified (needs a live SFTP server); no unit test.
